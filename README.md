# 📊Gestion d'une boutique avec Python
## 🎯Objectif
Bottleneck est un marchand de vin prestigieux qui possède un ERP contenant les références des produits, leur prix et les informations sur les stocks et un site web contenant les données des produits vendus sur le site web ainsi que les quantités vendues
Le but du projet est de faire une analyse des ventes du site internet.  
Pour cela je me suis appuyée sur 3 fichiers:
- **ERP** qui contient l'identifiant, le prix d'achat, le prix de vente et les informations de stock d'un produit
- **WEB** qui contient l'identifiant, le nombre de vente par produit, le détail du produit sur le site et les avis des utilisateurs sur le produit
- **Liaison** qui contient la correspondance entre l'idenfitiant du produit dans l'ERP et l'identfiant du produit sur le WEB
## 🛠️Outils
- Python
  - **Pandas** : Analyse et exploration des données
  - **Seaborn**, **Plotly** et **Matplotlib** : Visualisation des données
## 🚀Résultats
Les taux de marges sont excellent, les prix de vente sont bien fixés par rapport au prix d’achat
